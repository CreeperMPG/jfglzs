# RefConfig.cs — 强类型资源管理器桩（自动生成）

## 文件作用
VS 强类型资源生成器（StronglyTypedResourceBuilder）产物：为 `WindowsApplication1.Resources` 资源提供 `ResourceManager` 单例与 `Culture` 属性。本组件当前无资源属性被使用（无真实资源成员），仅框架桩。

## 说明
- `ResourceManager` 指向 `WindowsApplication1.Resources`（该程序集内嵌资源，可能含本组件 UI/数据资源）。
- `RunRegistry()` 为恒 true 桩。
- 无恶意行为，无 IOC。
