# Form2.Designer.cs — 窗体设计器自动生成代码（Dispose）

## 文件作用
VB.NET WinForms 设计器自动生成的 partial 类代码，仅包含 `Dispose(bool)` 释放组件容器 `_InfoConfig` 的逻辑。

## 说明
- 自动生成文件，无任何手工恶意逻辑。
- `_InfoConfig` 为 `IContainer` 容器（对应 Form2.cs 中 `TestUtils` 里创建的 Container，承载 Timer_frm2 等组件）。
- 与 Form2.cs 共同构成 Form2 类；真正的卸载/密码逻辑在 Form2.cs。
