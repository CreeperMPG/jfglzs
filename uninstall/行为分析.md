# uninstall 行为分析

> 所属家族：机房管理助手（jfglzs13）· 组件定位：**卸载器（受控退出通道）**
> 分析基于反混淆还原后的代码（`decompiled/uninstall/`），非恶意样本运行观察。

## 一、程序概览

`uninstall` 是家族的"官方卸载程序"，带**全屏强制交互界面**（"卸载小助手"）。它要求输入卸载密码，验证通过后执行完整的 20 步卸载流程（`RegConfig.RunFullUninstall`），把家族安装的注册表项、服务、随机进程全部清掉，并恢复壁纸、释放鼠标，7 秒后退出。内部类混淆为 `*Config` 系列（ClassConfig/ConfigConfig/ContextConfig/OrderConfig/PoolConfig/RefConfig/RegConfig/UtilsConfig/VisitorConfig）。

## 二、界面与交互流程

### Form1（卸载入口）
- 卸载程序启动后的入口窗体，挂接 Form2 显示流程

### Form2（卸载确认窗——"卸载小助手"）
用户交互流程：
1. 全屏、置顶、**不可关闭**（FormClosing 强制取消）
2. 显示"卸载小助手密码"输入框 + 「确定」/「重启电脑」按钮
3. **Timer_frm2 每秒把鼠标夹在屏幕顶部区域**并周期性蜂鸣（强制交互）
4. 输入 6 位以上密码 → SHA256 哈希比对（`HKCU\Software\n`）
5. 校验通过 → `RegConfig.RunFullUninstall` 完整卸载 → 恢复默认壁纸 → 锁定鼠标 → **7 秒后退出**
6. 另有「重启电脑」按钮：`shutdown /r /f /t 0`；界面附带 QQ/官网联系方式

## 三、核心行为（RegConfig 卸载流程，20 步）

`RunFullUninstall` 依次执行（原控制流混淆已还原）：

1. **杀进程**：结束 zmserv 与随机名同伴进程、枚举击杀"f~o 字符集"命名进程
2. **停/删服务**：`net stop zmserv` → `sc delete zmserv`
3. **删注册表**：清除 `HKCU\Software\jfglzs`、`HKCU\Software\n` 等家族键
4. **恢复策略**：USB、CMD、注册表编辑器、浏览器快捷方式、hosts
5. **删文件**：清除 `C:\windows\jf\`、`C:\Program Files (x86)\<随机名>\` 等
6. **恢复壁纸/外壳**：恢复默认壁纸（`SPI_SETDESKWALLPAPER`）、重启 explorer

### 辅助机制（OrderConfig）
- **MD5 计算**（`ComputeMd5Hash`）：文件完整性/校验
- **AES 加密**（`AesEncryptString`）：内嵌字符串解密
- **反篡改补丁**（`ApplyAntiTamperPatch`）：对自身做完整性保护
- **程序集解析钩子**（`RegisterAssemblyResolveHandler`/`OnAssemblyResolve`）：动态加载内嵌 DLL

### 密码校验
- `ComputePasswordHash`：SHA256(明文 + "bfdshgs")
- 读注册表 `HKCU\Software\n` 比对

## 四、与其他组件的关系

- **→ zmserv**：卸载核心动作是删除 zmserv 服务（必须先 `net stop`，否则被看门狗强制关机）
- **→ jfglzsn**：杀 jfglzsn 相关进程与随机名进程
- **← about**：about 的 Form3 与 uninstall 功能重叠（about 侧重"退出恢复"，uninstall 侧重"完整卸载"）
- **与 set 对称**：set 负责"装上"，uninstall 负责"卸下"

## 五、持久化与配置

| 项 | 值 |
|----|----|
| 密码 | SHA256(明文+"bfdshgs")，存 `HKCU\Software\n` |
| 目标服务 | zmserv |
| 目标注册表 | `HKCU\Software\jfglzs`、`HKCU\Software\n` |
| 目标文件 | `C:\windows\jf\`、`Program Files (x86)\<随机名>\` |
| 附带功能 | 重启电脑按钮、QQ/官网联系方式（伪装正版） |

## 六、危害总结

- **双重性质**：它既是"卸载器"，也是**强制交互勒索界面**——不输密码就无法关闭窗口、鼠标被锁、蜂鸣报警
- **密码门槛**：只有知道卸载密码的人才能卸载（学生/网管没有密码就被锁死）
- **与看门狗联动**：卸载流程必须与 zmserv 时序配合（先杀服务再删），否则触发强制关机
- **防御价值**：uninstall 的 20 步流程完整揭示了家族的"卸载清单"——即清除本家族所需的所有动作，是应急处置的现成手册

> 结论：uninstall 是家族的"受控卸载器"，其密码门 + 全屏强制交互是防止用户自行清除的关键设计；分析它等于拿到了家族的全部清理清单。
