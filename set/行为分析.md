# set 行为分析

> 所属家族：机房管理助手（jfglzs13）· 组件定位：**设置主控界面（管理端）**
> 分析基于反混淆还原后的代码（`decompiled/set/`），非恶意样本运行观察。

## 一、程序概览

`set` 是家族里**唯一面向"管理员"的图形界面**——窗体标题「设 置」，自称"机房管理小助手"（官网 **www.jfglzs.com**）。它由 `load` 密码门验证通过后进入（`Reader.MyForms.Form1.Show()`），负责把管理员勾选的策略**批量施加到学生机**。内部类被混淆重命名成 `*Mock` 系列（ConfigurationMock/CreatorMock/DicMock/HelperMock/TestMock/Watcher 等）。

## 二、界面与交互流程

### load.cs（密码门）
- 程序入口（`ExceptionMock.InvokeProperty` → `Application.Run` 显示 load 窗体）
- 输入正确密码后放行，显示主设置界面 Form1
- 附带 SHA256 加盐哈希（盐 `"bfdshgs"`）+ CryptoAPI + 注册表读写

### Form1（「设 置」主界面）
管理员勾选限制项 → 点保存 → 以管理员权限**批量执行全部限制策略**：

1. 禁用 USB / 杀软 / CMD / 注册表编辑器 / 小游戏
2. 篡改 hosts 屏蔽网站
3. 替换桌面浏览器快捷方式为**假浏览器**
4. 创建防删除服务 zmserv
5. 隐藏文件
6. 关闭防火墙与安全模式
7. 禁用 IPv6
8. 最后**杀 explorer 重启外壳**（让策略立即生效）

### Form3 / 其他 Internal 类
- Form3：辅助设置窗体
- Internal/Reader.cs：`ReflectProperty.load` 引用（入口装配）
- Internal/Watcher.cs 等：策略监控/执行辅助

## 三、核心行为

### 批量限制执行（保存设置时一次性施加）
- **注册表策略**：USB 存储禁用（`usbstor` Start=4）、DisableCMD、DisableRegistryTools、关闭安全模式等
- **文件系统**：hosts 追加屏蔽域名、替换浏览器快捷方式（指向假浏览器 exe）
- **服务**：`sc create zmserv` 安装看门狗
- **系统设置**：`netsh` 关防火墙、禁用 IPv6
- **外壳重启**：杀 explorer.exe 强制刷新桌面

### 假浏览器替换（重点恶意行为）
- 把桌面/开始菜单的浏览器快捷方式目标改为家族的假浏览器程序
- 用户点击"浏览器"实际打开的是被控制的页面/程序（配合 hosts 屏蔽形成流量劫持链）

## 四、与其他组件的关系

- **→ jfglzsn**：set 保存的策略由 jfglzsn 的定时器持续执行/自愈
- **→ zmserv**：set 负责创建 zmserv 服务
- **→ przs**：przs 的文件监控保证 set 写入的 hosts/文件不被改回
- **← load**：load 密码门是 set 的入口保护

## 五、持久化与配置

| 项 | 值 |
|----|----|
| 注册表 | `HKCU\Software\jfglzs`（策略项）、`HKCU\Software\n`（密码哈希） |
| 密码 | SHA256(明文+"bfdshgs")，6 位以上 |
| 官网 | www.jfglzs.com（伪装成正常产品） |
| 服务 | 创建 zmserv（防删除） |
| 系统改动 | hosts、浏览器快捷方式、防火墙、IPv6、安全模式 |

## 六、危害总结

- **管理端入口**：这是攻击者/管理员控制整机的"遥控器"，所有限制策略在此配置
- **一次性批量破坏**：保存设置即对系统做 8 类持久性破坏
- **伪装性强**：自称"机房管理小助手"、有官网，属于典型的"流氓软件全家桶"商业化包装
- **入口保护**：密码门防止学生自行打开设置改回策略

> 结论：set 是家族的"控制面板"，恶意策略的源头；清除家族时，除了杀进程/删服务，还必须恢复 set 施加的注册表与文件改动。
