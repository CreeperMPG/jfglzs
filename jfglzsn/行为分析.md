# jfglzsn 行为分析

> 所属家族：机房管理助手（jfglzs13）· 组件定位：**核心主程序 / 驻留调度器**
> 分析基于反混淆还原后的代码（`decompiled/jfglzsn/`），非恶意样本运行观察。

## 一、程序概览

`jfglzsn` 是家族**大脑**：隐藏窗口常驻后台（无边框、最小化、不在任务栏），靠 **14 个定时器**分阶段执行全部恶意动作。它同时拥有两个全屏锁屏窗体（Form2 一级锁屏、Form4 二级密码锁屏），是"学生机房管理助手"里控制力最强的一环。

## 二、界面与交互流程

- **Form1**：隐形主窗体（`FormBorderStyle.None` + `ShowInTaskbar=false` + 最小化），无可见界面
- **Form2（一级锁屏）**：全屏、置顶、**不可关闭**；输入正确密码（`HKCU\Software\n` 哈希比对）→ 执行 `UninstallAndExit` 卸载流程；每秒 `ClipCursor` 把鼠标锁在屏幕顶部 100px 区域并周期性 Beep 报警
- **Form4（二级密码锁）**：与 Form2 几乎相同，但密码可匹配主密码或二级密码（`HKCU\Software\jfglzs\n2`）；卸载时额外处理 DisableCMD 恢复（临时放开 cmd 执行 `net stop zmserv` 再恢复）；关闭受 `ModelVisitor.lockFormCanClose` 控制

> 用户视角：正常使用时看不到 jfglzsn 的任何窗口；一旦触发保护（如杀进程），屏幕上会出现**无法关闭的锁屏**。

## 三、核心行为（14 个定时器全拆解）

| 定时器 | 周期 | 职责 |
|--------|------|------|
| Timer_main | 3s | **启动序列总调度**：按计数逐步启用各定时器（见下） |
| Timer_usb | 5s | 禁用 U 盘（`usbstor` Start=4） |
| Timer_dzjs | 16s | **电子教室进程守护**：进程缺失→从 `.exe2` 副本恢复并拉起；暂停/无响应计数超阈值→锁屏报警；连续 5 次未找到→强制关机 |
| Timer_wangluo | 17s | 网络/IP 监控：检查 IP 配置，异常时报警/恢复 |
| Timer_jcm | 5s | 进程监控（杀毒软件/进程工具检测） |
| Timer_fhq | 13s | 强制关闭防火墙（`netsh advfirewall set allprofiles state off` 类操作） |
| Timer_qdx | 3s | 注册表保护：恢复被篡改的家族注册表项（防清除） |
| Timer_jiyu | 15s | 极域电子教室参数与服务监控（拉起被停的极域相关服务） |
| Timer_updatehosts | 10s/60s | hosts 自愈：从服务器下载黑名单改写 `hosts`，备份为 `hosts2` |
| Timer_route | 11s | 封堵 IP 路由（屏蔽特定地址） |
| Timer1/Timer2/Timer3/Timer4 | 1s~6s | 辅助轮询/报警/锁屏联动 |

**启动序列（Timer_main 调度）**：
1. 读 `HKCU\Software\jfglzs\zhuye`（服务器地址）
2. 下载黑名单写 hosts（`http://<zhuye>/hmd_net.txt`）
3. 按计数启用 USB 禁用、防火墙关闭、网络监控、电子教室守护等
4. 计数 12：进程存在则启用 Timer_dzjs，随后停 Timer_main（启动序列结束）

## 四、恶意行为细节

### 安全软件对抗
- **360 系列进程黑名单**：`360safe.exe`、`360taskmgr`、`360netman.exe`、`360zippp.exe` 等（进程哈希列表存于 ComparatorVisitor 的 uint 数组）
- **腾讯电脑管家**：监控 `tdfilefilter`/`tdnetfilter` 服务状态，阻止其运行/强制操作

### hosts 篡改
- 读取 `C:\Windows\System32\drivers\etc\hosts`，处理 `127.0.0.1` 行，合并服务器下发的黑名单域名后写回
- 先备份 `hosts` → `hosts2`（自愈用，被删可从副本恢复）

### 服务安装与自愈
- `sc create zmserv binPath= ... start= auto` 安装看门狗服务
- 检测到 `net stop zmserv` 后重新创建（自我修复）

### 网络行为
- `WebClient` 下载黑名单/更新
- `TcpClient.BeginConnect` 端口探测（探测目标可达性）

### 强制关机（自我保护）
- 电子教室进程连续 5 次 NotFound → `ForceShutdown()`（RtlAdjustPrivilege + NtShutdownSystem） + `shutdown /s /f /t 0`
- 锁屏触发卸载 → `net stop zmserv` + 杀随机名进程

## 五、与其他组件的关系

- **→ zmserv**：安装并维护看门狗服务；zmserv 反过来监控 jfglzsn 进程（被杀→强制关机）
- **→ set**：set 是设置入口，jfglzsn 执行 set 保存的策略（USB/防火墙/浏览器等）
- **→ about**：about 的 Form3 退出流程击杀 jfglzsn 相关进程
- **→ przs**：同族兄弟，przs 负责文件系统监控与持久化，jfglzsn 负责定时调度

## 六、持久化与配置

| 项 | 值 |
|----|----|
| 注册表 | `HKCU\Software\jfglzs`（zhuye/dzjs/usb_jianche…）、`HKCU\Software\n`（主密码） |
| 文件 | `C:\windows\jf\`、hosts2 备份、`.exe2` 进程副本 |
| 服务 | zmserv（sc create 安装） |
| 随机进程名 | 日期种子（月×日）生成 4~5 字符 |
| 服务器 | 从 `HKCU\Software\jfglzs\zhuye` 读取，下载 `hmd_net.txt` 黑名单 |

## 七、危害总结

- **强驻留**：多定时器自愈 + hosts 自愈 + 服务自愈，单点清除无效
- **反杀软**：针对 360/腾讯电脑管家主动对抗
- **反卸载**：锁屏 + 杀进程强制关机，用户无法自行清除
- **破坏性**：禁 USB、关防火墙、改 hosts、替换浏览器入口，影响正常使用

> 结论：jfglzsn 是家族的"执行核心"，所有策略落地和自我保护都围绕它展开；清除时必须与 zmserv、about/uninstall 的退出流程配合。
