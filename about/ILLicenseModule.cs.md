# ILLicenseModule.cs

## 文件作用

IntelliLock 授权体系留下的静态桩类型。名字里的 `ILLicense` 指 IntelliLock（一个商业 .NET 加壳/授权工具），与样本后来使用的 .NET Reactor 不是同一套壳，说明这批程序至少在某个版本上叠加/更换过保护方案。

类型里只有两个恒返回常量的方法，**没有任何授权判断逻辑**，且全工程没有任何调用点。

## 类与职责

| 类/模块 | 真实职责 |
| --- | --- |
| `ILLicenseModule` | IntelliLock 授权桩。两个方法分别恒返回 `true` / `false`，不读注册表、不读许可证文件、不联网校验 |

## 反混淆命名映射

| 混淆名 | 反混淆名 | 说明 |
| --- | --- | --- |
| `ForgotFacade()` | `返回真占位()` | 恒 `return true;`，IntelliLock 的「许可有效」占位实现 |
| `DefineFacade()` | `返回假占位()` | 恒 `return false;`，成对出现的另一半占位 |

## 关键方法与流程

1. `返回真占位()`：直接 `return true;`。无参数、无副作用。
2. `返回假占位()`：直接 `return false;`。无参数、无副作用。

两者都没有被调用，是本文件唯一的两个方法。

## 恶意行为 / 敏感操作

无恶意行为。属于壳/授权工具的残留代码，不是业务逻辑，也不是反调试手段（不做任何检测动作）。
