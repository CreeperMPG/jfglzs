# przs 行为分析

> 所属家族：机房管理助手（jfglzs13）· 组件定位：**主控驻留 + 文件系统监控**
> 分析基于反混淆还原后的代码（`decompiled/przs/`），非恶意样本运行观察。

## 一、程序概览

`przs` 是家族里"隐藏最深"的成员：**启动即隐藏，驻留托盘图标**，同时承担文件系统监控、自复制持久化和注册表强制策略。它的命名空间里有一个随机 GUID 混淆命名空间 `gypZRX1vuWc3aeye0R`（ConfuserEx 特征），内含 Account/Broadcaster/Callback/Initializer/Object/Param/Schema/Status 等"通信框架"类。界面方面有托盘图标、`bianhao` 悬浮编号窗和若干窗体（Form1~Form4）。

## 二、界面与交互流程

- **Form1（主控窗体）**：启动后立即隐藏（托盘驻留），无可见主界面
- **托盘图标**：右键菜单/点击交互——**点击托盘图标会启动 about.exe**（家族入口衔接）
- **bianhao（编号悬浮标）**：透明小悬浮窗，屏幕右上角用 65 号黑体大字显示**计算机名后 6 位**（机房机器编号标识）；鼠标悬停提示"由机房管理助手自动生成"；由 `HKCU\Software\jfglzs\bianhao=on` 控制显示
- **Form2~Form4**：辅助窗体（含编号相关界面逻辑）

## 三、核心行为

### 1. 文件系统监控（FileSystemWatcher 群）
- 挂载**多个 FileSystemWatcher** 监视桌面、下载、全盘目录
- **删除"违规"文件**：发现不符合规则的文件（如杀毒软件安装包、清理工具）立即删除——"禁止下载安装"策略
- **hosts 自愈**：hosts 被改回 → 立即恢复成家族版本

### 2. 7 个 Timer 定时任务
- 进程/文件自愈（被杀恢复）
- 禁用 USB 存储
- 禁止浏览器游戏
- 注册表强制策略（定期写回，防手动修改）

### 3. 自我复制持久化（核心恶意行为）
- 自我复制到 **`C:\Program Files (x86)\<随机名>\`**
- 写入注册表自启动：**`HKLM\...\Run` 键名 `prozs`**
- 与 zmserv 的随机进程名机制配合，形成多层躲藏

### 4. gypZRX1vuWc3aeye0R 通信框架
- 混淆命名空间下的 Account/Broadcaster/Callback/Initializer/Object/Param/Schema/Status 类
- 疑似用于组件间通信/回调封装（反混淆后仍保留框架性质，无独立网络 C2 证据）

## 四、与其他组件的关系

- **→ about**：托盘点击启动 about.exe
- **与 jfglzsn 平行**：jfglzsn 管定时调度/服务，przs 管文件监控/持久化，互为备份
- **→ 注册表 Run 键**：开机自启（`prozs`），独立于 zmserv 服务实现双持久化

## 五、持久化与配置

| 项 | 值 |
|----|----|
| 自复制路径 | `C:\Program Files (x86)\<随机名>\` |
| 注册表 | `HKLM\...\Run`（键名 `prozs`）、`HKCU\Software\jfglzs`（bianhao 等） |
| 监控目标 | 桌面/下载/全盘目录、hosts 文件、USB 存储 |
| 显示标识 | bianhao 悬浮窗（计算机名后 6 位） |

## 六、危害总结

- **双持久化**：Run 键 + 文件监控自愈，删文件/删键都会复活
- **主动防御**：删除"违规"文件（杀软/清理工具安装包），阻止用户安装防护软件
- **隐蔽性**：无主窗口、托盘驻留、随机目录名，难以发现
- **标识作用**：bianhao 编号窗暴露机房机器编号（对攻击者可用于批量管理）

> 结论：przs 是家族的"持久化+文件监控"节点，负责让整个家族在用户删除任何文件/注册表项后自动复活；清除时需先断其文件监控和 Run 键。
